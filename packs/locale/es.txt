# Praise-spam openers in Spanish. Matched at message open (after optional

# no-sycophancy.sh — sycophancy_validation (Tier 2)
#
# Validation-amplification phrases in Spanish (ELEPHANT validation dimension).
# Matched anywhere in the full response text. Covers phrases that validate the
# user's perspective/framing without independent warrant.
#
# Positive test coverage:
#   "Tienes toda la razón, este enfoque es el más adecuado."
#   "Tu teoría es fascinante y tiene mucho mérito."
#   "Tu hipótesis es bastante acertada y tiene sólidos fundamentos."
[sycophancy_validation]
# "Tienes toda la razón" — razón may be followed by comma, period, or preposition

# and calls:
#   load_locale_section anthropomorphization_strong
